### 🚀 Featured project: [BloomEval](https://bloomeval.my)

> Localized pedagogical and cognitive depth evaluation for ESL writing, powered by edge LLM-as-a-Judge and multimodal vision OCR.

<table>
  <tr>
    <td align="center"><h3>&lt; 2s</h3><sub>handwritten script to text</sub></td>
    <td align="center"><h3>&lt; 400 KB</h3><sub>client-side image payload</sub></td>
    <td align="center"><h3>r = 0.942</h3><sub>scoring parity (Pearson)</sub></td>
    <td align="center"><h3>RM0.00</h3><sub>monthly infra cost</sub></td>
  </tr>
</table>

- 📝 **Snap and grade.** Teachers photograph handwritten foolscap scripts. Canvas downscaling happens in the browser, and nothing is stored on the server.
- 📏 **Rubric-faithful.** Enforces official Lembaga Peperiksaan Malaysia band descriptors (SPM 1119 Paper 2): Content, Communicative Achievement, Organisation, Language.
- 🧠 **Thinking depth.** Maps every essay to Bloom's Revised Taxonomy, so feedback covers *how* students think, not just *what* they wrote.
- ☁️ **Edge native.** Cloudflare Pages + D1, serverless end to end.

**[🌐 Live platform](https://bloomeval.my)** · **[🧪 Staging engine](https://bloomeval-playground.pages.dev)**

### 🧩 How I build

| Principle | What it means |
|---|---|
| **Pedagogy first** | Start from the rubric and the teacher's workflow, then write code. |
| **Edge by default** | Low latency for every school, from KL to rural Sabah. |
| **Zero-cost production** | Free tiers, used carefully, so schools never pay for infra. |
| **Privacy by design** | Student work is processed, not hoarded. |
